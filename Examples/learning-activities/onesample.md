# [Examples Articles](../index.md)

## Learning Activities | One-Sample *t* Test

### Learning Outcomes

- Explain how a one-sample comparison evaluates a population mean relative to a meaningful reference value.
- Interpret the direction and size of the difference from the reference in the context of the outcome.
- Evaluate the strength and limits of evidence about the population mean and the practical meaning of any difference.

### Learning Sequence

- Identify the quantitative outcome, reference value, and comparison being tested.
- Locate the sample size, mean, and standard deviation; calculate the sample-minus-reference difference and note its direction.
- Calculate or verify the hypothesis test, including the test statistic, degrees of freedom, and *p* value, and interpret the result relative to the null hypothesis.
- Calculate or locate the confidence interval and Cohen's *d*. Some outputs give an interval for the mean difference, while R gives an interval for the sample mean that can be compared with the reference value; calculate the effect size when it is not reported.
- Summarize the descriptives, difference, test, confidence interval, and effect size in APA style.

### Discussion

- How would a different reference value change the estimated difference and the question the test answers?
- If a confidence interval includes both values below and above zero, what range of population differences remains plausible?
- What additional evidence would help determine whether a difference from the reference value matters in the setting where the outcome is measured?
