## Learning Activities | One-Sample *t* Test

### Learning Outcomes

- Explain how a one-sample comparison evaluates a population mean relative to a meaningful reference value.
- Interpret the direction and size of the difference from the reference in the context of the outcome.
- Evaluate the strength and limits of evidence about the population mean and the practical meaning of any difference.

### Learning Sequence

1. Use statistical software to obtain the mean, standard deviation, and the one-sample t test.
2. On your own, calculate the one-sample t test, the confidence interval for the difference, and the standardized effect size using the descriptive statistics given by the software. Verify that your calculations match the statistics provided by the software.
3. Using appropriate APA Style, report your results from this set of analyses.

### Discussion

- How would a different reference value change the estimated difference and the question the test answers?
- If a confidence interval includes both values below and above zero, what range of population differences remains plausible?
- What additional evidence would help determine whether a difference from the reference value matters in the setting where the outcome is measured?
